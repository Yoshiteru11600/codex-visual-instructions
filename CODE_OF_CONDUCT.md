# Code of Conduct

We are committed to a welcoming, harassment-free community. Be respectful, assume good intent, discuss technical disagreements with evidence, and protect other people's privacy.

Unacceptable behavior includes harassment, discriminatory language, threats, publishing private information, and sustained disruption. Maintainers may remove content or participation that violates these expectations. Report conduct concerns privately to the repository maintainers; the future public repository will publish an appropriate contact channel before accepting community reports.
