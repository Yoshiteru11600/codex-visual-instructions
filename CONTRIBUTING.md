# Contributing

Thanks for helping improve Codex Visual Instructions.

1. Open an issue for behavior changes or security-sensitive design work.
2. Keep v1 framework-neutral and local-first. Do not add telemetry or external services.
3. Create a focused branch, add tests for observable behavior, and run `pnpm check` plus `pnpm test:e2e` when browser behavior changes.
4. Explain the user-facing intent, implementation tradeoffs, and verification in the pull request.

By participating, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Contributions are licensed under MIT.
